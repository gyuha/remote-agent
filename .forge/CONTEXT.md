# remote-agent

메신저에서 로그인된 코딩 CLI를 폴더 단위 에이전트로 불러 쓰고 오케스트레이션하는 시스템의 용어집.

## Language

**에이전트**:
작업 폴더 하나에 속한 이름 붙은 설정 묶음 — CLI 종류, 모델, 역할 프롬프트, 권한 프로필. 한 폴더에 여러 개가 있을 수 있다.
_Avoid_: 봇, 워커, 프로필

**세션**:
에이전트 하나가 CLI를 실제로 실행해 이어가는 대화 한 줄기. CLI의 세션 ID에 대응하고, 메신저에서는 스레드 하나(텔레그램은 포럼 토픽 하나)에 대응한다. 에이전트 하나는 세션을 여러 개 가질 수 있다.
_Avoid_: 대화, 스레드, 인스턴스

**작업 폴더**:
에이전트가 CLI를 실행하는 디렉토리. 에이전트 정의 파일이 그 안에 있다.
_Avoid_: 워크스페이스, 프로젝트

**소유자**:
봇에게 명령할 수 있는 유일한 사람(허용된 메신저 사용자 ID).
_Avoid_: 사용자, 관리자
