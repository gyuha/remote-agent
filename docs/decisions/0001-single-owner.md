# 사용자 모델: 본인 1인 전용

봇에게 명령할 수 있는 사람은 소유자 한 명(허용된 메신저 사용자 ID)뿐이다. 그룹 채널에 봇이 있어도 소유자의 메시지만 실행한다. 이유: (1) Anthropic 약관은 본인이 수정하지 않은 `claude` 프로그램을 본인 구독으로 쓰는 것만 명시적으로 허용하고, 구독 자격증명으로 타인의 요청을 중계하는 것은 금지한다. `agy`도 Google의 계정 정지 사례가 있다 (`docs/research/2026-11-09-references.md` §4). (2) 봇은 폴더에서 코드를 실행하는 셸 권한과 같으므로, 사용자가 한 명이면 인증이 허용 ID 하나로 단순해진다.

## 기각한 대안
- 본인 + 신뢰하는 소수: 약관 위험이 있고, 사용자별 권한·폴더 접근 제어가 MVP 범위에 들어온다.
- 팀원 각자 자기 인스턴스: 구조는 1인 전용과 같다. 배포 편의성은 MVP 이후 과제로 둔다.

## 결과
다중 사용자로 바꾸려면 인증·권한 모델을 다시 설계해야 한다. 대화 데이터 모델에 사용자 차원을 미리 넣지 않는다.
