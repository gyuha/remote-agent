# 실행 위치: macOS와 Linux 둘 다 1급 지원

MVP부터 서버 프로세스는 본인 맥(launchd)과 상시 켜진 리눅스 서버(systemd) 양쪽에서 상주할 수 있어야 한다. 설치와 서비스 등록도 두 OS 모두 제공한다. 메신저 연결은 모두 바깥으로 나가는 방식(텔레그램 long polling, 디스코드 Gateway, 슬랙 Socket Mode)을 쓰므로 들어오는 포트는 필요 없다.

## 결과
- 범위가 늘어난다: 설치와 서비스 등록을 두 벌 만들고, 두 OS에서 모두 검증해야 한다.
- 리눅스에서 CLI 4종(특히 `agy`)이 화면 없이 로그인되는지 아직 확인하지 못했다.
- Windows는 지원하지 않는다.
