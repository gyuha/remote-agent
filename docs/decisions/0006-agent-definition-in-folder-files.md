# 에이전트 정의는 작업 폴더 안의 파일, 실행 상태는 SQLite

에이전트 정의(이름, CLI 종류, 모델, 역할 프롬프트, 권한 프로필)의 원본은 작업 폴더 안 선언 디렉토리의 파일 하나씩이다(frontmatter + 프롬프트 본문, Claude Code의 `.claude/agents/*.md`와 같은 방식). 정의가 git으로 추적되어 프로젝트와 함께 이동한다. SQLite에는 등록된 작업 폴더 목록, 세션, 로그 같은 실행 상태만 둔다. 웹 UI는 정의 파일을 편집하는 화면이다.

## 기각한 대안
- DB만: 구현은 가장 적지만 정의가 프로젝트와 함께 이동하지 않는다.
- 중앙 설정 파일 하나: 폴더별 정의가 한곳에 몰려 프로젝트와 분리된다.

## 결과
- 웹 UI 밖에서 파일을 고치면 감지해서 다시 읽어야 한다(파일 감시 또는 실행 시마다 읽기).
- 선언 디렉토리: `<작업 폴더>/.remote-agent/agents/<이름>.md` (2026-11-09 결정). `.agents/`는 다른 도구와 겹칠 수 있어 피한다.
