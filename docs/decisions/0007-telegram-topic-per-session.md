# 채팅 바인딩: 포럼 그룹 토픽 하나 = 세션 하나, DM = 기본 에이전트

텔레그램에서는 소유자와 봇만 있는 포럼 슈퍼그룹을 쓰고, 토픽 하나에 에이전트 하나의 세션 하나를 고정한다. 새 세션은 새 토픽이다(`createForumTopic`). 봇과의 DM은 빠른 질문용 기본 에이전트 하나에 연결한다. 이렇게 하는 이유는 병렬로 도는 에이전트(오케스트레이터의 하위 에이전트 포함)의 출력과 승인 버튼이 한 화면에 섞이지 않게 하기 위해서다. 2차의 디스코드·슬랙에서는 "스레드 = 세션"으로 그대로 옮긴다.

## 기각한 대안
- DM 하나 + `/use` 명령 전환: 단순하지만 병렬 실행 시 출력과 승인이 섞인다.
- 에이전트마다 봇 하나: 에이전트를 추가할 때마다 봇 토큰을 만들어야 해서 웹 UI 흐름과 맞지 않는다.

## 결과
- 최초 1회 설정이 필요하다: 그룹 생성, 토픽 기능 켜기, 봇을 관리자로 추가.
- 토픽이 쌓이므로 닫기와 보관 처리가 필요하다.
