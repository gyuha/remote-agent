# 관리자 웹 UI: 127.0.0.1 바인딩, 원격은 사설망, 텔레그램 일회용 로그인 링크

웹 UI는 기본적으로 `127.0.0.1`에만 바인딩한다. 원격 서버(0003)에 접속할 때는 앱 바깥의 SSH 터널이나 Tailscale 같은 사설 VPN을 쓰고, 공용 인터넷에 직접 노출하는 경로는 만들지 않는다. 앱 인증은 텔레그램 일회용 로그인 링크로 한다. 웹 UI에서 로그인을 요청하면 봇이 소유자(0001) DM으로 5분 동안 유효한 링크를 보낸다. 이유: 이 UI는 권한을 `trusted`로 바꿀 수 있어서 뚫리면 원격 셸이 된다. 1인용 MVP에 공용 노출 보안(TLS, 무차별 대입 방어)은 과하다.

## 기각한 대안
- 설정 파일의 관리자 비밀번호: 관리할 비밀이 하나 더 생긴다.
- 공용 노출 지원: MVP 범위에 비해 보안 부담이 크다.

## 결과
휴대폰에서 원격 서버의 웹 UI를 쓰려면 폰에 VPN 클라이언트가 필요하다.
