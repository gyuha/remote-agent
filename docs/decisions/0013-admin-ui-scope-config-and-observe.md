# 관리자 웹 UI의 MVP 범위: 설정과 관찰까지, 입력은 메신저로만

**포함**
- 작업 폴더 등록과 해제
- 에이전트 CRUD: `.remote-agent/agents/*.md` 편집(0006), 권한 프로필과 허용 목록 포함(0009)
- 텔레그램 봇 토큰과 소유자 ID 설정
- 세션 목록과 상태: 실행 중, 대기 중, 승인 대기
- 세션 대화 로그 읽기 전용 보기
- 실행 중인 세션 중단

**제외**
- 웹에서 메시지 보내기(웹 채팅)
- 웹에서 승인하기

이유: 입력 채널이 둘이 되면 같은 세션에 동시에 들어오는 입력과 승인 동기화를 처리해야 한다. 이 시스템의 목적은 메신저에서 쓰는 것이다. 로그 보기는 텔레그램에서 보기 불편한 긴 출력과 도구 호출 세부를 위해 넣는다. 어댑터 이벤트(0008)를 어차피 SQLite에 저장하므로 추가 비용이 작다.
