# 로드맵 — MVP 이후 검토 항목

MVP 결정(`decisions/0001`~`0014`)을 내릴 때 일부러 미뤄 둔 것과, 아직 질문으로 만들 만큼 구체화되지 않은 것을 모았다. MVP를 만든 뒤 새 의제를 열 때 여기서 시작한다.

## 2차 후보 (결정 때 미룬 것)
- 메신저: 디스코드, 슬랙. "스레드 = 세션"으로 옮긴다(0004, 0007)
- CLI: OpenCode(`opencode serve`), Antigravity(`agy`. 권한이 막혀도 exit 0으로 끝나므로 별도 처리 필요)(0004)
- 리눅스에서 `agy`·OpenCode 헤드리스 로그인 확인(0003)
- 세션별 git worktree를 이용한 병렬 쓰기(0010)
- `trusted`에서도 적용되는 절대 차단 목록(0009)

## 아직 흐릿한 주제
- 예약 실행(cron)·주기 작업: cokacdir와 Hermes 모두 있지만, 이 시스템에 필요한지 아직 모른다
- 오케스트레이션 2단계: 비동기 위임, 병렬 팬아웃, 하위 에이전트 간 공유 컨텍스트. MVP의 동기 호출(0011)을 써 본 뒤에 질문이 된다
- 장기 메모리·스킬 축적: 각 CLI 자체 기능(CLAUDE.md, AGENTS.md)에 맡길지
- 사용량·비용 추적과 구독 한도 대응
- 여러 머신(노드)에 걸친 실행

## 범위 밖 (다시 열지 않음, 이유 포함)
- 자체 LLM 에이전트 루프(Hermes 방식): LLM 호출은 항상 로그인된 CLI가 한다
- CLI OAuth 토큰 추출·프록시: Anthropic·Google이 계정 정지로 단속한다
- 다중 사용자(0001), cokacdir 포크(0002), Windows(0003)
- 웹 UI 공용 인터넷 직접 노출(0012), 웹 채팅·웹 승인(0013)
